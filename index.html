Choose Your Framework

Two powerful options. One installer. Pick the one that suits your style.

Hermes Agent

by Nous Research

  • Skills system with curator & hub
  • Persistent memory (multi-backend)
  • Multiple isolated profiles
  • Built-in cron job scheduler
  • 20+ providers, native MCP
  • Config: YAML (~/.hermes/)

OpenClaw

AI Agent Framework

  • Gateway-based architecture
  • Tool calling & sessions
  • 30+ built-in providers
  • Custom provider support
  • Owner auto-approve
  • Config: JSON (~/.openclaw/)

Installation

Three commands. That's it.

# Clone the repository
git clone https://github.com/galinaplinoel-stack/Myfurina.git
cd Myfurina

# Run the installer
sudo chmod +x install.sh && sudo ./install.sh
1

Choose Framework

Pick between Hermes Agent or OpenClaw. The installer handles the rest.

2

Enter Credentials

API key, base URL, model name, Telegram bot token, and chat ID. All required fields are validated.

3

Start Your Agent

Run ~/.superagent/start.sh and chat via Telegram. Your agent is alive.
